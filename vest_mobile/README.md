# Vest Mobile

## Backend configuration

The app reads `BaseURL` from the bundled config at `App/Resources/Config.json`.
To set up your backend URL:

1. Copy `App/Resources/Config.json.example` to `App/Resources/Config.json` (or edit the existing file).
2. Update the `BaseURL` value.

Only `App/Resources/Config.json` is packaged with the app.
